# APP-SP Study · Visualizador TMA São Paulo

Site estático de estudo da TMA São Paulo, com mapa OpenStreetMap, pesquisa de fixos, limites de TMA e camadas de procedimentos por aeródromo, tipo e pista.

## Uso

1. Abra o site e escolha o aeródromo, o tipo de procedimento e a carta.
2. Adicione a camada para visualizar a sequência fixo por fixo quando houver ordem e coordenadas confirmadas no acervo.
3. Use **ATCSMAC** para consultar a carta oficial e os limites de TMA como contexto geográfico.

## Publicação no GitHub Pages

No GitHub, abra **Settings → Pages**, selecione **Deploy from a branch** e escolha `main` com a pasta `/ (root)`.

## Aviso

Ferramenta exclusivamente educacional. Cartas AIS/AIP, NOTAM, autorizações ATC e procedimentos vigentes sempre prevalecem. O site não deve ser usado para navegação ou operação real.
